# Retenção de backups

Os backups que possam conter documentos ou dados clínicos devem expirar em até 30 dias, o mesmo prazo da retenção operacional. Antes de qualquer implantação de produção, o administrador deve confirmar que o plano e a configuração do provedor permitem esse prazo; caso contrário, a implantação não está aprovada para dados reais.
